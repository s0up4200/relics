# App name: Relics, not Silo

The app is named Relics. It is an unofficial Silo client for Linux, with extras for Omarchy. The [Silo trademark policy](https://github.com/Silo-Server/siloserver.org/blob/main/TRADEMARK.md) reserves these names for the official project: "'Silo' on its own, or as the first word of a product name, including generic descriptors used as the name such as 'Silo Client' or 'Silo Player'". The old name `silo-omarchy` put "Silo" first, and the launcher, the window title and the media controls showed "Silo" on its own. The policy permits a client with its own name and a tagline that names Silo, without permission.

We looked at two options. We can keep `silo-omarchy` and ask the Silo project for permission, or we can use a new name. Permission can be refused or taken back, so we took a new name. The new name also drops "omarchy", because the app runs on any Wayland desktop. Omarchy adds only the live theme and a Hyprland rule that makes the window opaque. The name comes from the TV show Silo, where relics are the forbidden objects from before.

The domain words "Silo server" and "Silo library" stay, because they name the upstream product, and the policy permits that.
