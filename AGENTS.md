# silo-omarchy

silo-omarchy is a native Silo media player for Omarchy. The library window uses GPUI and gpui-omarchy. libmpv plays video in its own window.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on s0up4200/silo-omarchy. Use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The repo uses the six default triage labels. Each label has the same name as its role. See `docs/agents/triage-labels.md`.

### Domain docs

The repo has a single context, with `GLOSSARY.md` and `docs/adr/` at the root. See `docs/agents/domain.md`.
